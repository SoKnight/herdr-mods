Claude Threads

Your past Claude Code sessions, newest first, for the repo you're in or for every folder. Click one to pick it up again in a new tab, in the folder it ran in: the tab you closed an hour ago, or the conversation from last week you half remember.

Version 1.0.0Needs: Claude Code and GitSource on GitHub

Quick start

  1. Install with the prompt below.
  2. Open it with herdr-app do mod.open --name claude-threads, or the Threads button in Estro.
  3. Click a session to resume it. Shift-click to fork it.

Install

Read ~/.config/herdr-app/AGENTS.md, then add this mod: https://github.com/munza/herdr-mods/tree/main/claude-threads

The agent follows RECIPE.md. The mod reads ~/.claude/history.jsonl, the file names under ~/.claude/projects/ and ~/.claude/sessions/*.json, and writes none of them. It runs git rev-parse for the shown space's repo and hc get for each Claude terminal, and on a click opens a tab running claude. It reaches no network.

Install by hand

From a clone of the repository, sync.sh copies mods/claude-threads/ into Herdr's mods folder:

./claude-threads/sync.sh

On Windows, run .\sync.ps1 from PowerShell in the claude-threads folder instead.

mod.json has place: none: it opens as a 400×560 popup, or put {"id": "threads", "type": "block", "content": {"mod": "claude-threads"}} in a panel stack of your own layout and give it a Better Tabs button with the icon mods/claude-threads/icons/threads.svg.

Use

  • Two lists: the shown space's repo, and All, with each session's folder.
  • Search looks through every prompt you typed in a session, and the row then shows the one that matched.
  • Each row: the first prompt, how long ago it was used, how many prompts it has, and the last prompt.
  • Click opens a tab running claude --resume <id>; shift-click adds --fork-session, a new session with the same history.
  • Already open: a session running in a terminal says Open on the right, and a click goes to its tab instead of starting it twice.
  • Sessions Claude Code has cleaned up, or whose folder is gone, aren't listed, since they can't be resumed.

Limits: only this computer's sessions; in a space on another machine, a click opens a new space here. The title is your first prompt, not the name /resume shows, and there's no model: both live only in the session files, which can be 100 MB each. The list reloads every minute and on the refresh button.

Settings

Claude Threads has no settings.

Update

Copy mods/claude-threads/ into Herdr again, or run sync.sh.

For developers

threads.js holds the pure part: grouping history.jsonl into sessions, search, the ~/.claude/projects folder name, and which sessions are open. main.js is the view.

node --test claude-threads/tests/threads.test.cjs claude-threads/tests/packaging.test.cjs
./claude-threads/sync.sh
herdr-app check "$HOME/.config/herdr-app/mods/claude-threads"
